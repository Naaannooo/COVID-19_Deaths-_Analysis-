# COVID-19 Data Analysis — SQL

## Overview

This project analyzes global COVID-19 data using **SQL Server** to explore cases, deaths, infection rates, and vaccination progress across countries and continents.

## Key Analysis

* Death percentage by country
* Percentage of population infected
* Countries with the highest infection rates
* Countries with the highest death counts
* Global cases and deaths over time
* Vaccination progress and rolling vaccinations

## SQL Skills

* Joins
* Aggregations
* CTEs
* Window Functions
* Temporary Tables
* Views
* Data Transformation

## Tools

**SQL Server**

## Files

* `COVID-19-SQL-Analysis.sql` — SQL queries used for the analysis
